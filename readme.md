# WooCommerce XenithPay

WooCommerce XenithPay is a payment gateway plugin for WooCommerce that integrates XenithPay as a payment option for your online store.

## Features
- Seamless integration with WooCommerce.
- Secure payment processing via XenithPay.
- Support for WooCommerce blocks.

## Installation
1. Download the plugin files or clone the repository.
2. Extract the plugin zip to the `/wp-content/plugins/` directory. Or you can upload it via wordpress plugin.
3. Activate the plugin through the 'Plugins' menu in WordPress.

## How to Use
1. Navigate to WooCommerce > Settings > Payments.
2. Enable the XenithPay payment gateway.
3. Manage the gateway settings (You will get client keys after successfully register your merchant) :
   - Merchant Secret Key
   - API Key (or Xenith API Key)
   - Secret Key (or Xenith Secret Key)
   - Webhook Signature Secret Key
   - Payment URL
   - Merchant Number
   - Web Name
4. Save changes and start accepting payments via XenithPay.



For more information, visit https://docs.xenithpay.com/ to see more documentation.
